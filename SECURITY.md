# Security Policy

## Supported versions

Use the latest GitHub Release of [koupper-jvm/koupper](https://github.com/koupper-jvm/koupper/releases). The current supported line is **7.2.x**.

## Reporting a vulnerability

Report privately via [GitHub Security Advisories](https://github.com/koupper-jvm/koupper/security/advisories/new).

Do not open a public issue for security reports. We will acknowledge the report and coordinate a fix and disclosure.
